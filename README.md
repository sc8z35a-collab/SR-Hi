# STRATA B4｜地下研究所

スマホを横にして、地下研究所 STRATA B4 を探索する 3D ウォークスルー。

## 遊び方（ローカル）

ES モジュールを使っているので、ファイルを直接開くのではなく、簡単なサーバー経由で開きます。

```bash
python3 -m http.server 8000
```

そのあと、ブラウザで `http://localhost:8000/` を開きます。

## 増設棟から先の読み込み

増設棟から先（区画 06〜26 と屋外）は、探索を始めた直後から裏で少しずつ読み込みます。扉の前でまとめて読み込むことはありません。

- 画像のデコードは `createImageBitmap`、メッシュの展開は Worker、照明データの計算は `lighting-worker.js` で行い、いずれもメインスレッドの外で処理します。
- 地形や建物の組み立ては1フレームあたり 10ms ずつに分けます。扉の前で待っているときは 30ms、読み込み画面では 50ms に増やします。
- シェーダーは先に1つずつコンパイルします。テクスチャと頂点データは、プレイヤーの近く（描画距離＋30m 以内）から順に、1フレーム数ミリ秒ずつ GPU に送ります。初めて見えた瞬間にまとめて送ることがないため、引っかかりません。
- 増設棟の扉のボタンには準備の進み具合（%）を表示します。

## 軽量化

- テクスチャは使われている面積に合わせて縮小しています（画素数で全体の約 1/3.3。小物は 1/5〜1/6）。
- 地形と小物は 24m 四方のチャンクごとにまとめ、描画距離（設定のスライダー）より遠いチャンクや画面外のチャンクは描きません。
- 葉や岩の塊は、滑らかな球（三角形が約 1/3）に置き換えました。屋外では、画面に描く三角形が約 30 万から約 4 万に減っています。
- 箱型の物（家具、柱、建物）は角を面取りし、光の当たり方で丸みが出るようにしています。
- 水面、水車、換気扇などは止め、動くのは人物だけにしています。

## テクスチャ

`textures/` の画像はすべて GPT Image 2.5 Sunburst で生成したものです（1:1 の 2880×2880 を1枚生成し、3×3 に切り分けて9種類）。

- 一覧: `textures/manifest.json`（58シート・522種類）
- 追加の8シート・72種類: `facility-floors` / `facility-rock-concrete` / `facility-metal-finishes` / `facility-utility` の4枚は、まだ生成テクスチャにしていなかった施設の素材36種類の差し替え。`detail-underground` / `detail-rooms` / `detail-yard` / `detail-countryside` の4枚は、作り込み用の36種類。この8枚は別の場所で生成した 1254px の画像をスキルの `import` で取り込み、切り出しています
- さらに3シート・27種類（`facility-equipment` / `facility-doors-paint` / `facility-metal-rubber-rock`）で、残っていた施設の素材（黄色い鋳物、実験台の天板、注意喚起ストライプ、縞鋼板、緑の扉、床の標示ペイント、排水グレーチング、防振ゴムなど）を差し替えています
- 大浴場（24）用の4シート・36種類（`onsen-bath-surfaces` / `onsen-baths` / `onsen-dressing` / `onsen-lounge`）
- 社員食堂（25）用の4シート・36種類（`canteen-surfaces` / `canteen-kitchen` / `canteen-tableware` / `canteen-food`）
- 中央公園（26）用の7シート・63種類（`park-paths` / `park-play` / `park-water` / `park-planting` / `park-sports` / `park-facilities` / `park-forest`）- 色は濃くなりすぎないよう、切り出し時に彩度とコントラストを少し下げ、暗部を少し持ち上げています（`SKILL.md` の `tone`）
- 各シートの仕様（プロンプト）: `textures/specs/`
- シート全体の縮小版: `textures/sheets/`
- 生成スキル: `.claude/skills/texture-sheet/`（使い方は `SKILL.md`）

## ファイル構成（追加分）

| ファイル | 役割 |
|---|---|
| `cavern-layout.js` | 新区画の位置・歩ける範囲・当たり判定・床の高さ・照明 |
| `cavern.js` | 出入口、トンネル、空洞、観測棟、地底湖の 3D |
| `quarters.js` | 居住区画・和室・洋室・会議室の 3D |
| `surface.js` | 斜坑と坑口ヤード |
| `outdoor-layout.js` | 屋外の地形の高さ・川・道路・歩ける範囲・木の配置・区画20〜23（three.js を使わない計算だけ） |
| `outside.js` | 屋外の世界の 3D（地形、川と滝、道路と橋、本館、広場、台地、集落、木々、空と太陽） |
| `kit.js` | 部品づくりの共通処理（UV、同じ素材の結合、端末・看板・引き戸） |
| `props.js` | 各区画の小物（街・集落・キャンプ場・地下の研究設備・室内） |
| `park.js` | 中央公園（26）の 3D（広場、池、遊具、庭、運動施設、森） |
| `canteen.js` | 社員食堂（25）の 3D（食堂、配膳カウンター、厨房） |
| `onsen.js` | 大浴場（24）の 3D（脱衣所、休憩処、洗い場、檜風呂、水風呂、岩風呂、庭） |
| `details.js` | 作り込み用テクスチャを使った物（送風機と風管、足場、金屏風、コンテナ、キッチンカー、井戸、巣箱など） |
| `textures.js` | テクスチャの読み込みと既存素材の差し替え |
| `lighting-worker.js` | 照明データ（光の当たり方の地図）を Web Worker で計算し、描画を止めない |
