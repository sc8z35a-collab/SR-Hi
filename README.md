# STRATA B4｜地下研究所

スマホを横にして、地下研究所 STRATA B4 を探索する 3D ウォークスルー。

## 遊び方（ローカル）

ES モジュールを使っているので、ファイルを直接開くのではなく、簡単なサーバー経由で開きます。

```bash
python3 -m http.server 8000
```

そのあと、ブラウザで `http://localhost:8000/` を開きます。

屋外は約190m × 180mの起伏のある地形で、地面の高さに合わせて歩けます（鉄橋・木橋の上も歩けます）。

各区画には生活感のある小物も置いています（広場のカフェ席・駐輪場・分別ごみ箱・花壇・EV充電器、集落の水車小屋・干し柿・甕・薪棚・かかし・小舟と漁網、キャンプ場の椅子・望遠鏡・道標・百葉箱、地下の野外実験台・薬品ドラム・蓄電池、和室の桐箪笥・楽焼・生け花・盆栽、洋室のピアノ・地球儀・油絵、会議室のノートPCなど）。木は林と空き地ができるように自然な間隔で配置しています。

既存の部屋も、模様が乏しかった素材（塗装金属・エナメル・配管・壁・天井など）を生成テクスチャに差し替えています。

さらに作り込みとして、次の物を追加しています（`details.js`）。

- 地底空洞: 坑内送風機と黄色い風管（掘削リグへ）、ガスボンベ置き場、足場、工具の掛かった有孔ボード、ヘルメット棚、照明の周りの苔
- 地底湖: 水際の小石の帯
- 居住区画: 和室の金屏風と畳んだ布団、洋室のワインラック、廊下のキリム敷物・掲示板・上着掛け、会議室の木版画、管制室のサーバー前面
- 地上: 二段積みのコンテナ、セメント袋、ラップ巻きの荷、仮設トイレ、鉱石の山、樹脂バリケード、広場のキッチンカーと杉の植木箱
- 集落・渓谷・台地: ブルーシートの山、竹垣、井戸、無人販売所、干し大根、布団干し、ニホンミツバチの巣箱、消波ブロック、ラップサイレージ

## テクスチャ

`textures/` の画像はすべて GPT Image 2.5 Sunburst で生成したものです（1:1 の 2880×2880 を1枚生成し、3×3 に切り分けて9種類）。

- 一覧: `textures/manifest.json`（32シート・288種類）
- 追加の8シート・72種類（`textures/specs/facility-*.json` の4枚＝まだ生成テクスチャにしていなかった施設の素材36種類、`detail-*.json` の4枚＝作り込み用36種類）は仕様とゲーム側の組み込みまで済んでいます。生成は次のコマンドで行い、`manifest.json` に入った時点でゲームに反映されます（それまでは元の見た目／仮の色で表示）。

  ```bash
  python3 .claude/skills/texture-sheet/scripts/texture_sheet.py all textures/specs/facility-*.json textures/specs/detail-*.json
  ```
- 色は濃くなりすぎないよう、切り出し時に彩度とコントラストを少し下げ、暗部を少し持ち上げています（`SKILL.md` の `tone`）
- 各シートの仕様（プロンプト）: `textures/specs/`
- シート全体の縮小版: `textures/sheets/`
- 生成スキル: `.claude/skills/texture-sheet/`（使い方は `SKILL.md`）

## ファイル構成（追加分）

| ファイル | 役割 |
|---|---|
| `cavern-layout.js` | 新区画の位置・歩ける範囲・当たり判定・床の高さ・照明 |
| `cavern.js` | 出入口、トンネル、空洞、観測棟、地底湖の 3D |
| `quarters.js` | 居住区画・和室・洋室・会議室の 3D |
| `surface.js` | 斜坑と坑口ヤード |
| `outdoor-layout.js` | 屋外の地形の高さ・川・道路・歩ける範囲・木の配置・区画20〜23（three.js を使わない計算だけ） |
| `outside.js` | 屋外の世界の 3D（地形、川と滝、道路と橋、本館、広場、台地、集落、木々、空と太陽） |
| `kit.js` | 部品づくりの共通処理（UV、同じ素材の結合、端末・看板・引き戸） |
| `props.js` | 各区画の小物（街・集落・キャンプ場・地下の研究設備・室内） |
| `details.js` | 作り込み用テクスチャを使った物（送風機と風管、足場、金屏風、コンテナ、キッチンカー、井戸、巣箱など） |
| `textures.js` | テクスチャの読み込みと既存素材の差し替え |
