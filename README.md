# STRATA B4｜地下研究所

スマホを横にして、地下研究所 STRATA B4 を探索する 3D ウォークスルー。

## 遊び方（ローカル）

ES モジュールを使っているので、ファイルを直接開くのではなく、簡単なサーバー経由で開きます。

```bash
python3 -m http.server 8000
```

そのあと、ブラウザで `http://localhost:8000/` を開きます。

## テクスチャ

`textures/` の画像はすべて GPT Image 2.5 Sunburst で生成したものです（1:1 の 2880×2880 を1枚生成し、3×3 に切り分けて9種類）。

- 一覧: `textures/manifest.json`（20シート・180種類）
- 各シートの仕様（プロンプト）: `textures/specs/`
- シート全体の縮小版: `textures/sheets/`
- 生成スキル: `.claude/skills/texture-sheet/`（使い方は `SKILL.md`）

## ファイル構成（追加分）

| ファイル | 役割 |
|---|---|
| `cavern-layout.js` | 新区画の位置・歩ける範囲・当たり判定・床の高さ・照明 |
| `cavern.js` | 出入口、トンネル、空洞、観測棟、地底湖の 3D |
| `quarters.js` | 居住区画・和室・洋室・会議室の 3D |
| `surface.js` | 斜坑と地上ヤード、空と山並み、屋外の霧の切り替え |
| `kit.js` | 部品づくりの共通処理（UV、同じ素材の結合、端末・看板・引き戸） |
| `textures.js` | テクスチャの読み込みと既存素材の差し替え |
